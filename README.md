# NABO 钓鱼小岛

FoloToy AI Passport ESP32-C3 的独立离线钓鱼游戏。上、下键切换项目，OK 确认。浮漂跳动后，在指针进入金色区域时按 OK 收竿。钓到的鱼自动换成贝壳，用于升级四级鱼竿。升级会扩大收竿窗口，并解锁新鱼。

v0.2.0 重绘了 240×320 界面、NABO 钓鱼服和湖畔场景。100 种鱼均有独立插画，图鉴分十册，按上下键翻册或翻鱼，OK 打开或返回。目录末项可回到岸边。开机有「NABO，陪你钓鱼」语音，可按任意键跳过。抛竿、咬钩、上鱼、脱钩和升级有不同音效。游戏读取工牌已有的扬声器和音量设置，休眠唤醒直接回首页。

贝壳、鱼竿和图鉴写入独立的 `nabo_fish/progress_v2`。旧版 `progress_v1` 可读入，首次新增进度时写入新版存档。约五分钟无操作进入深睡，按键可唤醒。存档失败时界面提示并重试。

Windows 使用 `./build.ps1`，以 ESP-IDF 6.0.2 和 LVGL 9.5.0 构建。合并镜像位于 `firmware/build-idf6/nabo-fishing-merged.bin`。已有进度的工牌应先识别实际分区并备份，再评估应用分区升级。全量镜像从 `0x0` 安装会覆盖 NVS 所在区域。

运行 `node tests/test_rules.js` 可对拍生产 C 和浏览器规则。测试需要宿主 C 编译器，可用环境变量 `CC` 指定。v0.2.0 的对拍覆盖 8,996 步，含钓齐 100 种鱼、图鉴导航、升级和旧进度转换。硬件按键、画面、语音、休眠及断电恢复待真机验收。
